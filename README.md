# Detective Board (Foundry VTT v13)

> **0.1.1 - предварительная сборка для испытаний в игровом мире.** JS проверен на синтаксис, но в живой установленной Foundry v13 сборка ещё не проходила интеграционное тестирование. Перед первым запуском сделайте резервную копию мира.

Детективные доски для расследований в Call of Cthulhu, D&D, Cyberpunk RED и других системах. Стилистика: классическая пробковая доска, бумага, красные нити.

## Установка через Foundry

В менеджере дополнений Foundry выберите установку по URL манифеста:

`https://github.com/puskovdaniel-stack/foundryvtt-detective-board/releases/latest/download/module.json`

Каждый пуш в `main` публикует актуальный пакет в GitHub Release через Actions. Если релиз ещё не готов, используйте ручную установку ниже.

## Установка (вручную)

1. Остановите Foundry.
2. Поместите папку `detective-board` из ZIP в `FoundryVTT/Data/modules/`. Название каталога должно быть **строго `detective-board`**.
3. Включите модуль `Detective Board` в вашем игровом мире на Foundry **v13**.
4. Откройте детективные доски кнопкой в панели инструментов сцены (обычно инструменты «Заметки») или кнопкой в разделе «Журналы».
5. Если кнопки не появились, откройте консоль Foundry (F12) и выполните:

   ```js
   game.modules.get("detective-board").api.open();
   ```

## Создание доски и права

- У GM полный доступ, пользователю-создателю назначается `OWNER`.
- При создании доступны личный, общий и режим просмотра, а также индивидуальные права.
- Нескольким игрокам можно назначать `OWNER` одновременно. Они могут изменять доску даже без активного подключения GM, **если сервер Foundry работает**.
- Чтобы игрок мог **создать** доску и личные хранилища заметок, GM обязан разрешить роли создание Journal Entries в Foundry.
- Для изменения прав после создания откройте меню `...` в библиотеке досок. Изменения прав может ограничивать сервер Foundry для не-GM; при необходимости назначайте права как GM.
- Не открывайте журнал-хранилище Detective Board в обычном редакторе журнала для ручного изменения страниц.

## Возможности версии 0.1.1

- Журналы модуля помещаются в папку `Detective Board`. При входе GM старые журналы модуля автоматически переносятся туда. Если папка ещё не создана, требуется вход GM.
- Выделенную карточку можно отправить в корзину клавишей Delete или Backspace, затем восстановить из корзины.
- Перетаскивание Scene создаёт карточку сцены.
- Создание нескольких независимых досок, шаблоны («пустая», «расследование», «персонажи», «хронология»).
- Простые бумажные карточки: название, тип, изображение (путь/URL), описание, общие заметки, теги.
- Двойной клик по карточке - редактор, перетаскивание за заголовок - изменить положение.
- Перетаскивание Actor, Item, Scene, JournalEntry/JournalEntryPage из Foundry на полотно; ссылки добавляются только если все наблюдатели доски имеют достаточные права на исходник. Иначе создаётся безопасная публичная заготовка без UUID и изображения.
- Инструмент нити: выберите две карточки. Нажатие на подпись нити позволяет её изменить / удалить.
- Масштабирование колесом, перемещение полотна средней кнопкой или инструментом «Рука», кнопка «Показать всё».
- Поиск по названию, тегам, описанию.
- Мягкое удаление карточек (галочка «Переместить карточку в корзину» в редакторе), восстановление через «Корзину».
- Личные заметки пользователя сохраняются в отдельных журналах с индивидуальными правами; GM может просмотреть заметки участников в редакторе карточки, если доступны соответствующие документы.
- История действий (до 100 последних записей, best-effort) и снимки после изменений с интервалом не чаще одного раза за 15 минут (сохраняется до 12 снимков).
- Экспорт JSON и импорт JSON. Ссылки UUID намеренно не восстанавливаются при импорте в другой мир. Личные записи и закрытые данные не включаются в обычный экспорт.

## Важные ограничения v0.1.1

- Модуль использует `JournalEntry` для доски и `JournalEntryPage` для карточек/нитей. В стандартном журнале эти страницы могут быть видны владельцам - не храните в них секреты.
- Доступ уровня `OWNER` в Foundry даёт **полные** права на документ, включая изменение данных вне интерфейса модуля. Отдельной безопасной роли «редактор без прав администратора» здесь нет.
- Проверка UUID выполняется при перетаскивании. При последующем изменении прав доступа существующий UUID остаётся метаданными публичного журнала, хотя Foundry всё ещё ограничивает само открытие оригинального документа. Для строго секретных данных используйте публичную карточку без UUID.
- Файлы по URL не защищаются правами JournalEntry. Не указывайте секретные картинки, доступные пользователям по прямой ссылке.
- JSON-экспорт не встраивает изображения, он сохраняет их пути. Без соответствующих ресурсов в другом мире картинки могут отсутствовать.
- Настоящее разрешение одновременных правок одного текстового поля, полная история с гарантиями транзакционности, операции слияния, граф гипотез, хронология, PNG-экспорт ещё не реализованы.
- Заметки в карточках не поддерживают HTML, вводимый текст выводится с экранированием. Это защищает от внедрения разметки, но в первой версии нет редактора форматирования.
- GM отключён: журнал с `OWNER` можно редактировать, но новые личные журналы требуют права Create Journal Entries.

## Репозиторий

Исходники публикуются в репозитории `foundryvtt-detective-board`. Workflow `.github/workflows/release.yml` автоматически создаёт или обновляет GitHub Release с архивом `detective-board.zip` и манифестом `module.json` при пуше в `main`. Версия берётся из `module.json`.

## Структура

- `src/main.js` - подключение к Foundry и кнопки запуска.
- `src/manager.js` - библиотека и создание досок.
- `src/editor.js` - полотно, карточки, нити, редакторы.
- `src/store.js` - JournalEntry, данные, история, снимки, заметки и JSON.
- `src/utils.js` - вспомогательные функции.
- `styles/board.css` - оформление.
